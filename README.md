# Hyperlocal Marketplace

This repository contains a complete frontend scaffold for the hyperlocal marketplace MVP described by the user. Built with Vue 3, Vite, TypeScript, Pinia, Vue Router and Tailwind CSS.

## Features included (frontend MVP)
- Sign up / Login (email/phone + OTP flow)
- Seller profile & verification UI
- Quick listing flow (photo + title + price + tags)
- Browse / Search by locality, category, tags, filters
- Product detail + seller profile + contact/buy
- Cart & checkout UI (payment placeholders for UPI/credit/wallet)
- Seller order management (accept/decline, mark status)
- Ratings & reviews UI
- Admin moderation dashboard (basic)
- Notifications (in-app + push placeholders)
- Basic client-side fraud checks (rate limiting hooks)

## Run
1. `npm install`
2. create `.env` (see `.env.example`)
3. `npm run dev`
